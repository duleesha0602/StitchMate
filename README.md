StitchMate – Tailor Customer Management & Custom Measurement Locker System

Project Overview

StitchMate is a web-based application designed to help tailors manage customer information, custom measurements, orders, and work schedules efficiently.

Main Features

Customer Management

Custom Measurement Locker

Order Management

Work Schedule Management

Notifications

Tailor and Customer Dashboards

Profile Management

Sinhala and English Language Support

Technologies Used

HTML

CSS

Bootstrap

JavaScript

PHP

MySQL

Project Purpose

The main purpose of StitchMate is to simplify tailor-customer management and securely store customer measurement details in one system.
